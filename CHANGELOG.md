# Changelog

Release dates are the dates of publication. Changes in an unpublished candidate
remain under **Unreleased** until the release is published.

## Unreleased — v0.1.2 candidate (prepared 2026-11-21)

- Country names appear on the settled globe. Toggle them through
  **View → Country Names** on Classic Mac OS or the F2 tools window on X11.
- Labels use installed system fonts and country-specific Natural Earth positions.
  No fonts or network data are bundled for this feature.

[Draft v0.1.2 release notes](docs/release-notes-0.1.2.md)

## 0.1.1 — 2026-11-19

- Added a map scale, north-following compass and in-app controls help.
- Added a warning when an enlarged Classic window exceeds available application
  memory.
- Removed the AppearanceLib dependency from hand cursors, improving startup
  compatibility with older PowerPC Mac OS releases.
- Added a hybrid HFS/ISO CD image alongside the StuffIt download.
- Launched the project website with screenshots and installation instructions.

[Release v0.1.1](https://github.com/jackwillis/poodle-earth/releases/tag/v0.1.1) ·
[Release notes](docs/release-notes-0.1.1.md)

## 0.1.0 — 2026-11-13

- Initial public preview of the offline PowerPC Classic Mac OS globe.
- Added globe rotation and zoom, Map and Relief views, country and city selection,
  information cards, night shading and distance measurement.
- Distributed the Classic application as a StuffIt archive with matching source
  and checksums.

[Release v0.1.0](https://github.com/jackwillis/poodle-earth/releases/tag/v0.1.0) ·
[Release notes](docs/release-notes-0.1.md)
