## Fixed-mask losses and shared reference

Let K=3|M|, with M fixed independently of candidates and R. For any known encoded candidate x,

\[
\ell_x([L,U])=[\operatorname{dist}(x,[L,U]),\max(|x-L|,|x-U|)],\quad
E_X\in K^{-1}\sum_{pc\in M}\ell_{X_{pc}}([L_{pc},U_{pc}]).
\]

Full-frame MAE uses the same formula with every pixel. Worst pixel-channel error is enclosed by
[max_j ell_j.lower,max_j ell_j.upper]. For an empty frozen mask preserve the runner's MAE0;
report it as empty, not evidence of feature fidelity. Outside-mask changed-pixel count is exact
from candidate/background and fixed mask, requiring no numerical reference.

For D_AB=E_A−E_B, use the SAME r in h(r)=|a−r|−|b−r|. Extrema occur at L,U and any in-range a,b.
Sum those scalar intervals with the same K. Identical candidates give exactly[0,0], even with a
wide reference. Subtracting separate loss intervals is safe but needlessly loose; sampling separate
reference errors for A and B is not the experiment. Reference errors are not independent pixels,
styles, replicates or additional observations. Cross-pixel/color correlations may be relaxed to a
box for a conservative bound, never claimed independent to reduce uncertainty.

Midpoint m=(L+U)/2 gives |E_X(R)−E_X(m)|≤u_M=sum(U−L)/(2K) and paired difference deviation≤2u_M.
These are generic bounds; direct shared-r extrema can be tighter. Existing4800tile certificates give
u_full=152644143077/5257039970304000≈2.903614e−5 and2u_full≈5.807228e−5. For an arbitrary nonempty
fixed mask only u_M≤1/2560,2u_M≤1/1280 follow without its actual restricted sum. Full-frame empty
background cannot be used to dilute uncertainty in the stroke-neighborhood estimand.

## Discrete outcomes, ties and sequential control

For normalized t and M=31 or63, Q_M(t)=floor(Mt+1/2); exactly half ties round UP. Its conservative
code set is every integer from Q_M(L) through Q_M(U), inclusive. At a singleton exact tie only the
upper code is possible. Expand output codes with the frozen bit-replication mapping, not q/M.
Cartesian channel sets are safe supersets, not jointly achievable packed pixels.

For once-quantized control loss |expand(Q(r))/255−r|, retain Q's dependence on r. Partition[L,U] at
(2k+1)/(2M). Within each code cell evaluate piecewise-linear losses at endpoints and absolute-value
kinks. Half-open cells can use their closures to bound infimum/supremum conservatively; Q endpoint
sets must still respect exact ties. This avoids pretending that R and Q(R) are independent. The
frozen quantizer need not minimize error over bit-replicated channel values; do not replace it by
an optimized quantizer or clip negative excess errors. Unique quantized codes are sufficient but
NOT necessary for a bounded continuous-reference decision.

Sequential control needs per-feature UNION coverage a_fp∈[l,u], not full-color final bounds alone.
Use q=floor(255a+1/2), and carry every possible q. With expanded source s,destination d:

\[
z_c=\lfloor(qs_c+(255-q)d_c+127)/255\rfloor,\quad
v_c=\lfloor(z_cM_c+127)/255\rfloor.
\]

Use one shared q for all channels, pack the resulting RGB565 pixel, then process the next original
source feature. The demonstrator enumerates bounded packed state sets; exhaustion returns UNKNOWN,
never truncates states. Cartesian choices across features relax geometric correlation and may widen
results. Preserve source order. q0/q255 preserve destination/write source as in the original contract.

Coincident red/blue half-pixel features have opaque continuous RGB(0,0,1/2); disjoint halves give
(1/2,0,1/2). Their marginal coverages are identical and sequential output is0x4010 for red then blue;
reverse order gives0x8008. Thus sequential control is neither the continuous target nor a universal
lower error floor. Full-color final intervals cannot recover hidden earlier feature coverages.
Future control-error bounds must jointly retain a possible packed state S and R, or relax S×R
conservatively. Shared alpha couples channels; a final channel-wise range is not a feasibility proof.
No geographic coverage generation or sequential scorer is implemented here.

## Point gap, floor and local guard

Let N=mean(E_A−E_B), D=mean(E_A−E_Q), G=N/D for each style; sequential-control ratios remain separately
labeled sensitivity diagnostics. Means weight16geometries equally, not pixels across differently
sized masks. If D.upper≤10/1024, floor-limited. If D.lower≤10/1024<D.upper, denominator eligibility
is uncertain: inconclusive. Only D.lower>10/1024 permits a percentage statement. Never clamp D or
select favorable reference/control codes. G is safely enclosed by all endpoint quotients N/D.

For the20% point target, a tighter route bounds H=N−(1/5)D directly with common r and Q(r):
(4/5)|a−r|−|b−r|+(1/5)|Q(r)−r|. Use the quantization-cell partition above. If D is eligible,
H.lower≥0 proves the point target; H.upper<0 proves it fails; otherwise inconclusive. Ratios may be
negative or exceed1; do not clip them. The synthetic radius10^−6 control has midpoint G>0.2 and a
zero-width midpoint bootstrap interval, while a feasible shared reference gives G<0.2.

For each original condition let Δ=E_B−E_A, computed with shared reference. Bound
J=Δ−max(E_A/10,2/1024), using interval extrema (possibly loose but conservative).
J.upper≤0 proves that guard passes, J.lower>0 proves a violation; otherwise inconclusive. Equality
is permitted by the frozen threshold. Require every condition's guard; pooling cannot hide one.
Native confirmed loss of legibility/material stroke still needs human evidence; numerical visibility
is diagnostic and cannot waive that requirement.

## Reference-dependent eligibility and diagnostics

reference contrast C_p=a_ps_p. For s_p>0, true support is a_p>0. Classify as definite if l>0,

Visibility probes remain original nonzero-edge midpoints with the clipped3×3 neighborhood. Reference
eligibility is max(C_ref/s_p)≥1/10, including ties. Classify using max lower/upper ratios. Candidate
hit at the same threshold is deterministic on its isolated output; eligibility may be uncertain.

## Arithmetic and implementation limits

The demonstrator uses Fraction arithmetic and canonical rational endpoints. The percentile proof
uses exact mathematical probabilities1/40 and39/40 and linear interpolation; it does not claim
bit-for-bit equality with NumPy floating means/quantiles. Frozen float point outputs may remain
diagnostics, but certifying their literal rounding needs separately justified outward arithmetic.
A versioned instrument should retain exact endpoints as authority and round only displays outward;
an arbitrary tolerance must never move the20%/floor/regression boundary. Any approved float fast
path would need directed-error bounds, not empirical agreement alone.

Fixed-mask propagation is linear in channels; quantizer cells add bounded local work. The synthetic
implementation is not a full-frame performance result. Coverage certificates per feature and packed
state propagation can dominate cost: at most65536 packed states per pixel, potentially256 alpha
choices per layer. The4096-demonstrator work cap returns unknown even if a more expensive deduplication
could later prove a smaller set. No full sequential scalability claim follows from the coarse frame.
