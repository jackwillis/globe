Globe — Classic PowerPC preview

A free-software, offline, software-rendered Earth for Classic Mac OS 9.
Pre-1.0 software: some compatibility and usability work remains unverified.

Requires Mac OS 9, Color QuickDraw and Appearance Manager.
Preferred Classic application memory partition: 24 MB.

Drag to rotate; double-click to center and zoom. Arrow keys turn.
+/- zoom; R resets; G graticule; B borders; N north; T drag mode;
S switches Map/Relief; Q or Escape quits; Command-Q chooses File > Quit.
P opens the Looks palette where supported.

Includes an embedded atlas, country/place data, one-degree elevation
and biome colors. No network connection required.
Menu, palette and cursor functionality is implemented but the complete
bare Mac OS 9 hardware acceptance checklist is still open. Tiger Classic
tests do not establish native OS 9 behavior or performance.
