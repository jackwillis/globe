# Raw data for docs/research/rsqrt-experiment-145.md (2026-11-16)

Host: x86-64 Xeon 2.1 GHz, 2 vCPU shared VM, g++ 13.3 / clang 18.1.3; PowerPC: GCC 12.4 `powerpc-linux-gnu` + qemu-user 8.2.2 (not G4, not NetBSD). See PROVENANCE.txt.
None of this is G4 evidence. `args.bin` (549 MB of logged `inverse_length` arguments) and frame dumps (about 1 GB) are regenerated by the scripts and not committed.

| File | Content |
| --- | --- |
| host-audit-*.json | Numerical audit per compiler configuration: P1, dense error, by-arc-angle, thresholds, exceptional inputs, logged-argument statistics |
| host-bench-*.json | Throughput/latency micro-benchmark, 21 interleaved blocks; min/median/max per cell |
| host-callgrind-*.jsonl | Whole-process instruction counts per variant (variant `base` has the call counter off, so calls = 0 there) |
| host-fullrender-*.json | A/B/B/A wall time with every raw sample and frame-chain hash |
| host-frame-compare-vs-base.jsonl, host-trace-base.json | Pixel-exact comparison of 1,764 frames per variant against baseline |
| host-counts-by-radius.json | Calls to `inverse_length` and to the subdivision `sqrt` per radius |
| atlas-arc-stats.txt | Angular length of the bundled atlas segments |
| ppc-asm/ | Emitted PowerPC assembly and instruction/call counts per candidate and `-mcpu`; real-TU library-call census; `frsqrte` access notes |
| ppc-qemu-*.json | PPC32 frames under qemu against host and against PPC baseline; with and without `-ffp-contract=off` |
| bits-*.json, bits-compare-ppc-vs-host.json, frsqrte-qemu-7400.json | Bit-level host-versus-PPC comparison; qemu `frsqrte` (not the hardware table) |
| simd/ | Autovectorization probe (compile only) |
| proposed/ | Two separate, **unapplied** production patches (comment only; comment plus guard) |
