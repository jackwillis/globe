Get started on Mac OS 9

Tested on a Power Mac G4 running Mac OS 9.2.2.

  1. Open the .sit file with StuffIt Expander.
  2. Copy the folder to your hard disk and open Poodle Earth.

Read the Classic ReadMe for v0.1.0 for controls and requirements.
