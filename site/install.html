Install Poodle Earth

The current public preview is a PowerPC Classic Mac application. NetBSD and Linux builds are available from source; other native platforms are not yet released.

Classic Mac OS 7–9 (PowerPC)

Download Poodle Earth v0.1.0. The application prefers a 24 MB memory allocation (12 MB minimum).

  1. Download the StuffIt archive (.sit) on your Mac or transfer it there.
  2. Expand it using StuffIt Expander on the Classic Mac.
  3. Copy the expanded folder to your hard disk and open Poodle Earth.

For full controls, memory notes and troubleshooting, consult the Classic ReadMe.

On a modern computer: Classic Mac emulators

These are independent third-party projects. Each has its own installation and file-transfer requirements; Poodle Earth does not include an emulator or an Apple operating system.

Infinite Mac — in your browser

  1. Open Infinite Mac and choose a PowerPC Mac OS environment.
  2. Use that machine's file-import instructions to bring in the Poodle Earth .sit archive. Import options vary by emulated machine; check its welcome screen.
  3. Expand the archive inside the emulated Mac and open Poodle Earth.

Poodle Earth has been tested in Infinite Mac on PowerPC Mac OS 7.1.2 and later.

ClassicMac — desktop emulator

  1. Install ClassicMac for your host operating system.
  2. Follow ClassicMac's instructions to create a PowerPC Mac OS guest using your own appropriately licensed system installation media.
  3. Transfer the Poodle Earth archive into the guest, expand it with StuffIt Expander and open the application.

Poodle Earth has been tested in ClassicMac with a Power Mac G4 guest running Mac OS 9.2.1. ClassicMac also supports a separate Tiger guest profile; that does not mean a native Mac OS X edition of Poodle Earth has shipped.

Systemless — experimental application runtime

Systemless runs Classic Mac applications without an Apple ROM or System Folder. It supports 68k and PowerPC application formats and can accept StuffIt archives. Follow its installation instructions and try the Poodle Earth .sit file directly. Poodle Earth compatibility has not yet been verified with Systemless.

NetBSD and Linux (build from source)

There is not yet a packaged desktop installer for these systems. On a supported development setup with CMake, a C++20 toolchain, Ninja and X11 development dependencies, follow the source build instructions:

  1. cmake -S . -B build -G Ninja
  2. cmake --build build
  3. ctest --test-dir build --output-on-failure
  4. Launch ./build/globe-x11 from an X11 desktop.

The specific compiler and target evidence is recorded in toolchain documentation. A successful cross-build alone does not establish compatibility on a target machine.

Other platforms

Windows, a standalone browser Reader and a multi-platform CD-ROM are prospective projects, not currently available downloads. Installation instructions will be added when each platform has a validated build and distribution method.
